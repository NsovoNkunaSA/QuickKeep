# Quick Keep
* Access it here : https://quick-keep-nsovo.vercel.app/

## Save your links. Keep your files close. Access them anywhere.

Quick Keep is a web application designed to help users save and organise important links and files in one place. It provides a convenient way to keep useful resources accessible across devices without having to send links to yourself or search through messages.

## Features

Save links: Store useful website URLs for quick access later.
File storage: Upload and access saved files through cloud storage.
User authentication: Sign in to access your saved resources.
Cloud database: Store saved items using Supabase.
Personalised access: Keep saved resources associated with the authenticated user.
Web-based access: Access the application through a browser.
Responsive interface: Designed for convenient use across different screen sizes.

## Tech Stack

* React =>	Building the user interface.
* Vite	=> Development server and build tool.
* JavaScript =>	Application logic.
* CSS =>	Styling and responsive layouts.
* Supabase	=> Authentication, database and backend services.
* PostgreSQL =>	Database for saved items.
* Supabase Storage =>	File storage.
* Vercel	=> Hosting and deployment.
* Git and GitHub =>	Version control and source code management.
